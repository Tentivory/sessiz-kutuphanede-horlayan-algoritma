# Sessiz Kütüphanede Horlayan Algoritma

> **Resmi bildiri:** Bu yazılım, 1923'ten beri kütüphanelerde yaşanan "kim horluyor" krizini çözmek için tasarlanmıştır. Çözmez. Horlamayı standartlaştırır.

## Ne işe yarar?

Hiçbir şeye. Ama çok ciddi durur.

Algoritma şunu yapar:

1. Rastgele bir "kitap raflarının akustik katsayısı" üretir.
2. Bu katsayıya göre horlama hecelerini (ıh, gırr, pöf, hnnng) seçer.
3. Sessizlik kuralını **protokolü ihlal ederek** ihlal eder.
4. İhlali resmi bir tutanak gibi basar.
5. Sonunda damga, imza, tarih ve isim koyar çünkü belgesiz horlama geçersizdir.

## Kurulum

```bash
python3 horla.py
```

Bağımlılık yoktur. Uyku da yoktur. Sadece iddia vardır.
